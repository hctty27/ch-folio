## Modifications

The downloaded OBJ was modified for this project by:

- rotating the vehicle so forward is the project's `+X` axis;
- applying non-uniform game-scale fitting to the existing wheelbase, track, and wheel radius;
- removing three source wheel copies and retaining one runtime wheel template;
- merging painted body sections into the `bodyPainted` runtime mesh;
- mapping rear light meshes to the existing blinker, brake, and reverse-light node names;
- exporting to glTF 2.0 binary (`.glb`) with embedded materials.
