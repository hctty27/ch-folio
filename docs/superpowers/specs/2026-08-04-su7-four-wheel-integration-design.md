# SU7 原始四轮集成设计

日期：2026-08-04

## 目标

将当前“从 SU7 源模型抽取一套轮子模板，再由运行时克隆四次”的方案，替换为“在转换阶段保留四组 SU7 原始车轮，并在运行时分别驱动四个独立轮组”。

本次只改视觉车轮资产与视觉驱动逻辑，不修改 Rapier 物理轮半径、悬挂、抓地力、车辆操控或驾驶舱相机。

## 已确认的现状

原始 SU7 源模型包含四组车轮几何：

- Mesh1–Mesh4
- Mesh5–Mesh8
- Mesh9–Mesh12
- Mesh74–Mesh77

当前 `scripts/convert_su7.py` 会排除这四组车轮，只选取其中一组作为 `wheelContainer / wheelCylinder` 模板；`VisualVehicle` 再克隆该模板四次。该流程丢失了原始四轮各自的位置、朝向和左右差异。

## 推荐架构

### 转换后的节点结构

```text
chassis
├── wheelFrontRight
│   ├── steerPivot
│   │   ├── rollPivot
│   │   │   ├── tire
│   │   │   └── rim
│   │   └── brake
├── wheelFrontLeft
│   ├── steerPivot
│   │   ├── rollPivot
│   │   │   ├── tire
│   │   │   └── rim
│   │   └── brake
├── wheelRearRight
│   ├── rollPivot
│   │   ├── tire
│   │   └── rim
│   └── brake
└── wheelRearLeft
    ├── rollPivot
    │   ├── tire
    │   └── rim
    └── brake
```

前轮由 `steerPivot` 负责左右转向，四个 `rollPivot` 只负责滚动。刹车盘或卡钳挂在转向节点下但不挂在滚动节点下，避免随轮胎一起旋转。

## 转换流程

1. 根据四组车轮几何中心识别前右、前左、后右、后左。
2. 对每组车轮分别应用车辆总变换，不再合并为单一模板。
3. 以每组车轮几何中心建立本地原点。
4. 将车轮滚动轴统一为运行时本地 `Z` 轴，并把必要旋转烘焙进几何。
5. 保留左右车轮各自的几何朝向，不再由运行时用 `rotation.y = Math.PI` 镜像。
6. 将轮胎、轮毂和刹车部件分别输出到固定命名节点。
7. 输出四轮节点位置，使其初始位置与现有物理轮基准位置一致。

## 运行时映射

现有物理轮索引保持不变：

- `0`：前右
- `1`：前左
- `2`：后右
- `3`：后左

`VisualVehicle.setWheels()` 不再克隆 `wheelContainer`，而是按名称读取四个独立轮组。

每帧数据流：

1. 读取对应物理轮 `basePosition` 和 `suspensionLength`。
2. 更新四个轮组的局部位置和悬挂高度。
3. 仅更新前轮 `steerPivot.rotation.y`。
4. 根据车辆前向速度和物理轮半径累积滚动角。
5. 更新每个 `rollPivot.rotation.z`。
6. 左右轮滚动方向按几何朝向统一后使用同一角度符号；转换阶段负责消除镜像差异。

## 兼容策略

为了避免旧资产立即失效，运行时先检测四个新节点：

- 全部存在：使用 SU7 四轮模式。
- 任一缺失：回退到现有 `wheelContainer` 克隆模式，并输出一次明确警告。

该回退只用于构建失败或旧资产，不作为长期主路径。

## 错误处理

转换脚本遇到以下情况必须失败并输出具体原因：

- 少于四组完整车轮；
- 无法根据中心坐标区分前后或左右；
- 任一轮组缺少轮胎或轮毂几何；
- 转换后轮子中心与目标物理轮位置偏差超过容差；
- 输出节点命名重复。

不允许静默退化为单轮模板。

## 测试

### Python 转换测试

- 四组源车轮全部被识别。
- 四个目标轮组名称唯一且完整。
- 每个轮组本地中心接近原点。
- 四个轮组在目标坐标中的位置对应前右、前左、后右、后左。
- 左右轮经过烘焙后共享统一滚动轴。
- 刹车节点不属于 `rollPivot` 子树。

### JavaScript 运行时测试

- 新四轮节点存在时不调用模板克隆路径。
- 物理索引与四个节点映射正确。
- 只有前轮响应转向。
- 四轮响应滚动，且滚动不会改变轮子侧面朝向。
- 悬挂只改变轮组位置，不改变滚动轴。
- 缺失节点时触发旧模式回退并产生一次警告。

### 构建与浏览器验收

- `npm test` 通过。
- `npm run build` 通过。
- 四个轮子静止时位于各自轮拱中心。
- 前进和倒车时轮子只绕车轴滚动，不翻成倾斜圆盘。
- 左右转向时只有前轮改变转向角。
- 刹车部件不随轮胎自转。
- 第一人称和第三人称下均无新增穿模。

## 非目标

本次不处理：

- 新建梅花轮毂几何；
- 更换轮胎品牌或纹理；
- 修改物理轮尺寸；
- 调整车辆轮距、轴距或悬挂参数；
- 修改驾驶舱相机。

当前目标是完整复用原 SU7 模型中已有的四组轮子，并正确接入现有车辆系统。
